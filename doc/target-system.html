Система целиком — от идеи до рефлексии с человеком в центре

Не «агент пишет сам». Контент проходит человеческий шлюз перед публикацией. Модель — дешёвая, глобальная (opencode-go), пользователь отвечает за claims и редакцию. Данные — строго привязаны к пользователю/команде.

Принцип
● Ядро — владеет состоянием, версиями, аудитом

Как работает целиком

Пользователь входит через Google, создаёт проекты, гонит идеи по конвейеру. Всё привязано к user_id.

Авторизация и владение данными

Просто и бесплатно: Google OAuth. Каждый материал, версия и публикация привязаны к пользователю.

без паролей · JWT · scope по user_id

🔐 Google Auth

  • Бесплатно, без хранения паролей, 2-клик вход
  • Модели/ключи AI — глобально, не на пользователя (как просишь)
  • Потом можно добавить team / приглашения — без смены схемы

2
Генерация через opencode-go — 2–3 дня
Глобальная дешёвая модель, 6 шагов, без выбора на пользователя
▾
Поток
  • plan_topic — дедуп по архиву
  • build_brief — audience, claims, риски
  • draft_canonical — markdown (opencode-go cheap)
  • render_variant — Telegram / FamilyOS
  • verify — ссылки, длина, запреты
  • prepare_review — diff + sources для человека
Конфиг глобально
  • AI_PROVIDER=opencode-go, AI_MODEL=qwen3-7b
  • ключи в env / K8s Secret, не в БД
  • в логах — prompt/model/version, публикация только approved версии
3
Адаптеры — 3–4 дня
FamilyOS (3 маппинга) + Telegram, outbox, retry
▾
  • FamilyOS: POST is_published=false → PATCH publish, reconcile
  • Telegram: текст/картинка, permalink, idempotency
  • webhook reactions, UTM links, rate-limit
  • Нужны: TELEGRAM_BOT_TOKEN, FAMILYOS_API_KEY
  • Contract tests на моке FamilyOS
4
Метрики + рефлексия — 1 неделя
Снапшоты 1h/24h/7d, нормализация, weekly совет
▾
  • collector: реакции, клики по UTM, edit distance
  • weekly reflection: observation / confidence / next_test / do_not_conclude
  • следующий бриф обязан показать использованные наблюдения

Готово когда

  • 10 брифов → 10 review-готовых драфтов, claim без source подсвечен
  • повторный publish не плодит дубли, рестарт не теряет очередь
  • пользователь видит только своё, модель — одна на всех

Не делаем в MVP

  • пер-пользовательский выбор модели, fine-tuning
  • Facebook, SaaS/billing, marketplace
  • автопубликация — только approve
